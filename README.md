## 🎯 О проекте

**Ansar Store** — это полнофункциональная backend-платформа для интернет-магазина, построенная на современном Python-стеке с использованием асинхронного программирования.

### Ключевые особенности:

- ⚡ **Асинхронная архитектура** на FastAPI для высокой производительности
- 🔐 **JWT аутентификация** с ролевым доступом (RBAC)
- 🛒 **Полный функционал e-commerce**: каталог, корзина, заказы
- 📦 **Модульная структура** для легкой масштабируемости
- 🗄️ **PostgreSQL** с асинхронным драйвером asyncpg
- 📊 **SQLAlchemy 2.0** ORM с типизацией
- 🔄 **Alembic** для миграций базы данных
- 🐳 **Docker** для контейнеризации

## 🏗️ Архитектура

### Архитектурный стиль
Проект использует **модульную монолитную архитектуру** с разделением на функциональные модули:

```
┌─────────────────────────────────────────────────────────┐
│                     API Gateway                          │
│                    (FastAPI Router)                      │
└────────────┬────────────────────────────────────────────┘
             │
    ┌────────┴────────┐
    │   /api/v1/      │
    └────────┬────────┘
             │
    ┌────────┴────────────────────────────────────────┐
    │                                                  │
┌───▼───┐  ┌────▼────┐  ┌────▼────┐  ┌────▼─────┐  ┌───▼────┐
│ Auth  │  │  Users  │  │Catalogs │  │  Orders  │  │Notific.│
│Module │  │ Module  │  │ Module  │  │  Module  │  │ Module │
└───┬───┘  └────┬────┘  └────┬────┘  └────┬─────┘  └───┬────┘
    │           │             │             │            │
    └───────────┴─────────────┴─────────────┴────────────┘
                              │
                    ┌─────────▼──────────┐
                    │   PostgreSQL DB    │
                    └────────────────────┘
```

### Слои приложения
Каждый модуль следует трехслойной архитектуре:

1. **API Layer (routers.py)** - HTTP эндпоинты и валидация запросов
2. **Business Logic Layer (services.py)** - бизнес-логика и правила
3. **Data Access Layer (crud.py)** - операции с базой данных
4. **Models Layer (models.py)** - определение структур данных

## 🚀 Быстрый старт

### Предварительные требования
- Docker и Docker Compose
- Python 3.11+ (для локальной разработки)
- Git

### Установка и запуск

1. **Клонировать репозиторий:**
```bash
git clone <repository-url>
cd ansar_project
```

2. **Создать .env файл:**
```bash
cat > .env << EOF
# Database
DATABASE_URL=postgresql+asyncpg://postgres:postgres@db:5432/mydb

# JWT
SECRET_KEY=$(openssl rand -hex 32)
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
REFRESH_TOKEN_EXPIRE_DAYS=7

# Email (опционально)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-password
EOF
```

3. **Запустить через Docker Compose:**
```bash
docker-compose up --build
```

4. **Применить миграции:**
```bash
# В отдельном терминале
docker-compose exec backend alembic upgrade head
```

5. **Приложение доступно по адресу:**
- API: http://localhost:8000
- Документация (Swagger): http://localhost:8000/docs
- Альтернативная документация (ReDoc): http://localhost:8000/redoc

## 📚 API документация

### Интерактивная документация
После запуска приложения доступна автоматическая документация:
- **Swagger UI**: http://localhost:8000/docs
- **ReDoc**: http://localhost:8000/redoc

### Основные эндпоинты

#### Аутентификация
```
POST   /api/v1/auth/register         Регистрация
POST   /api/v1/auth/login             Вход
POST   /api/v1/auth/refresh           Обновление токена
GET    /api/v1/auth/me                Текущий пользователь
```

#### Пользователи
```
POST   /api/v1/users/                 Создать пользователя
GET    /api/v1/users/                 Список пользователей
GET    /api/v1/users/{id}             Получить пользователя
PATCH  /api/v1/users/{id}/status      Изменить статус
DELETE /api/v1/users/{id}             Удалить пользователя
```

#### Каталог товаров
```
GET    /api/v1/products/              Список товаров
POST   /api/v1/products/              Создать товар
GET    /api/v1/products/{id}          Детали товара
GET    /api/v1/products/search        Поиск товаров
GET    /api/v1/products/filter        Фильтрация товаров
GET    /api/v1/categories/            Список категорий
GET    /api/v1/brands/                Список брендов
```

#### Заказы и корзина
```
GET    /api/v1/orders/cart            Получить корзину
POST   /api/v1/orders/cart/items      Добавить в корзину
DELETE /api/v1/orders/cart/items/{id} Удалить из корзины
POST   /api/v1/orders/orders          Создать заказ
GET    /api/v1/orders/orders          Список заказов
GET    /api/v1/orders/orders/{id}     Детали заказа
PATCH  /api/v1/orders/orders/{id}/status  Изменить статус
```

#### Уведомления
```
GET    /api/v1/notifications/         Список уведомлений
GET    /api/v1/notifications/unread-count  Количество непрочитанных
PATCH  /api/v1/notifications/{id}/read     Отметить прочитанным
DELETE /api/v1/notifications/{id}     Удалить уведомление
```

## 👨‍💻 Разработка

### Локальная разработка без Docker

1. **Создать виртуальное окружение:**
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

2. **Установить зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настроить PostgreSQL локально** или использовать Docker только для БД:
```bash
docker run --name ansar_db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=mydb -p 5432:5432 -d postgres:16
```

4. **Обновить .env для локальной БД:**
```bash
DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/mydb
```

5. **Применить миграции:**
```bash
alembic upgrade head
```

6. **Запустить приложение:**
```bash
cd backend
uvicorn src.main:app --reload --host 0.0.0.0 --port 8000
```

### Создание миграций

```bash
# Автоматическая генерация миграции
alembic revision --autogenerate -m "Description of changes"

# Применить миграции
alembic upgrade head

# Откатить миграцию
alembic downgrade -1
```

### Тестирование

```bash
# Запустить тесты (когда будут реализованы)
pytest

# С покрытием
pytest --cov=src tests/
```
