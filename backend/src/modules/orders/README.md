# 🛒 Модуль Orders (Заказы и Корзина)

> **Часть проекта:** Ansar Store - Интернет-магазин  
> **Назначение:** Управление корзиной покупок и обработка заказов

---

## 📌 Контекст проекта

Модуль Orders - это ключевой компонент e-commerce платформы, который связывает пользователей с товарами через механизм корзины и заказов. Работает в связке с модулями Users (кто покупает), Catalogs (что покупают) и Notification (уведомления о заказах).

**Роль в системе:** Превращает желание купить в конкретные заказы с отслеживанием статусов.

## 🔗 API Эндпоинты

### Корзина
```
POST   /api/v1/orders/cart/items        Добавить товар в корзину

GET    /api/v1/orders/cart/items         Получить товары в корзине
```

### Заказы
```

GET    /api/v1/orders/orders             Получить заказы пользователя
GET    /api/v1/orders/orders/{id}        Получить заказ по ID
PATCH  /api/v1/orders/orders/{id}/status Обновить статус заказа
```

## 📝 Техническое задание

### 1. Проверка наличия товара (КРИТИЧНО)
**Задача:** Перед добавлением в корзину проверять, есть ли товар на складе

**Где реализовать:** `services.py`

**Что нужно сделать:**
```python
async def check_product_availability(
    db: AsyncSession,
    product_id: int,
    quantity: int
) -> bool:
    """
    1. Получить товар из каталога (используя catalogs.crud)
    2. Проверить product.in_stock == True
    3. Проверить product.availability_count >= quantity
    4. Вернуть True/False
    """
```

**Подсказка:** Нужно импортировать `from modules.catalogs import crud as catalog_crud`

---

### 2. Обновление остатков товара (КРИТИЧНО)
**Задача:** При создании заказа автоматически уменьшать количество товара

**Где реализовать:** `services.py`

**Что нужно сделать:**
```python
async def update_product_stock(
    db: AsyncSession,
    order_items: list[OrderItem]
):
    """
    Для каждого товара в заказе:
    1. Получить Product из БД
    2. Уменьшить product.availability_count на quantity
    3. Если остаток = 0, установить product.in_stock = False
    4. Сохранить изменения
    
    ВАЖНО: Обернуть в транзакцию!
    """
```

**Подсказка:** Используйте `async with db.begin()` для транзакции

## 🔍 Важные детали

### OrderStatus (статусы заказа)
```python
class OrderStatus(str, enum.Enum):
    accepted = "принят"      # Заказ создан, ожидает обработки
    delivery = "доставляется" # Передан в доставку
    delivered = "доставлено"  # Доставлен клиенту
    cancel = "отменено"       # Отменен
```

**Переходы статусов:**
- `accepted` → `delivery` (менеджер)
- `delivery` → `delivered` (менеджер/курьер)
- `accepted` → `cancel` (пользователь/менеджер)

### Связи с другими модулями
```
Orders ←→ Users      (user_id FK)
Orders ←→ Catalogs   (product_id в CartItem/OrderItem)
Orders  → Notification (отправка уведомлений)
```

## ❓ Частые вопросы

**Q: Как добавить новое поле в Order?**  
A: 1. Добавить в модель `models.py`, 2. Создать миграцию `alembic revision --autogenerate`, 3. Применить `alembic upgrade head`

**Q: Как обернуть операции в транзакцию?**  
A: Используйте `async with db.begin():` - при ошибке всё откатится автоматически

**Q: Где хранить бизнес-логику?**  
A: В `services.py` - там должны быть функции с проверками, расчетами, интеграциями

**Q: Нужно ли дублировать цену из Product в OrderItem?**  
A: Да! Цена товара может измениться, но в заказе должна остаться та, за которую купили
